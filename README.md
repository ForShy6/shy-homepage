## 技术要点

**纯静态**
HTML + CSS + 原生 JS，没有框架、没有构建步骤，一个 `index.html` 加几个资源文件就是全部。

**零第三方请求**
字体、图标、图片、音频、视频全部本地托管。没有 CDN、没有统计脚本、没有外部 API，断网也能打开（视频除外）。

**中文排版**
- 标题用得意黑，正文用霞鹜文楷，分工明确；
- 按页面实际出现的 575 个字做过字体子集化，两个 woff2 合计约 167KB（原始文件 21MB）；
- 两套字体都是 OFL 1.1 协议，可免费商用。

**性能**
- 首屏传输从最初的 6.7MB 压到约 500KB：视频改 `preload="none"` + 封面图、图片按 2 倍显示尺寸降采样、背景转 WebP；
- 滚动与动效只写 `transform` / `opacity`，全部交给合成器；用 6 倍 CPU 降速模拟低端机实测，平均帧时间 16.7ms，没有一帧超过 33ms；
- 弹窗里的舒尔特方格改为点击时才加载，避免首屏拉两份。

**移动端**
- 900px 以下出现右侧章节指示点，告诉用户当前在第几屏；
- 小屏弹窗自动铺满全屏；
- 悬停效果只在有指针的设备生效，触屏走 `:active` 按下反馈，不会出现「点完一直亮着」。

**无障碍**
- `<main>` + 跳过导航链接、`focus-visible` 焦点环、复制结果用 `aria-live` 播报；
- 弹窗打开时背景加 `inert`，焦点进入弹窗并在关闭后还原；
- `prefers-reduced-motion` 下打字机、数字滚动、视差全部停止；
- 关掉 JavaScript 时正文与技能数值仍然正常显示（`<noscript>` 兜底）。

## 本地预览

页面用到了字体与 iframe，直接双击 `index.html` 打开会因为 `file://` 限制加载不到字体，建议起一个本地服务：

```bash
cd shy-homepage
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```
